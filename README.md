# ParDL — دانلودر موازی

فایل را به تکه‌های ۲ مگابایتی (قابل تنظیم) تقسیم می‌کند، همه تکه‌ها را هم‌زمان با چندین اتصال می‌گیرد و مرتب در فایل نهایی می‌چیند.

## استفاده
- `ParDL.exe` را اجرا کن؛ مرورگر باز می‌شود (آدرس `http://127.0.0.1:8765`). لینک را بگذار و «شروع».
- حالت خط فرمان:
  `ParDL.exe -url "https://.../file.zip" -n 32 -chunk 2 -all-ifaces`
- چند میرور از همان فایل: لینک‌ها را با ویرگول (CLI) یا در چند خط (رابط) بده.

## بیلد
هر push در GitHub Actions تست می‌شود و `ParDL.exe` به‌عنوان Artifact ساخته می‌شود.
برای Release: تگ `v1.0.0` بزن.
