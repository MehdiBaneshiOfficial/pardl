# ParDL — شتاب‌دهنده‌ی دانلود سیستمی

یک پراکسی محلی که دانلودهای بزرگ **همه‌ی برنامه‌ها** را تکه‌تکه و موازی می‌گیرد.

## استفاده
1. `ParDL.exe` را اجرا کن (پراکسی ویندوز خودکار تنظیم می‌شود و داشبورد باز می‌شود).
2. دانلود را در برنامه‌ی خودت شروع کن. در داشبورد می‌بینی چه چیزی شتاب گرفته.
3. با Ctrl+C یا دکمه‌ی توقف ببند تا پراکسی ویندوز برگردد. اگر ناگهانی بسته شد: `ParDL.exe -restore`

## تنظیم خودکار
برای هر دانلود، تعداد اتصال و اندازه‌ی تکه‌ها بر اساس سرعت واقعی مدام تغییر می‌کند (اول ۱ اتصال، بعد دو برابر تا وقتی فایده دارد، بعد آزمایش‌های ریز بالا/پایین). اگر موازی‌سازی روی یک سرور فایده نداشته باشد، برای آن سرور خودش خاموش می‌شود و ترافیک عادی رد می‌شود.

## محدودیت
- فقط ترافیک **HTTP** (بدون رمزنگاری) که برنامه از پراکسی سیستم بخواند قابل شتاب است. HTTPS فقط تونل می‌شود.
- برنامه‌ای که پراکسی سیستم را نادیده بگیرد اصلاً دیده نمی‌شود.

گزینه‌ها: `-port 8899 -n 16 -chunk 2 -min 8 -all-ifaces -no-sysproxy -no-browser`
حالت لینک مستقیم: `ParDL.exe -url "https://..."`
